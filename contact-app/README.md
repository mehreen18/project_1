# Contact App

A full-stack contact management web app built with React, Express, and MySQL.

## Tech Stack
- Frontend: React (Vite) + React Router
- Backend: Node.js + Express
- Database: MySQL

## How to Run This Project

### 1. Setup Database
- Open MySQL Workbench
- Run the `database.sql` file to create the database and tables

### 2. Setup Backend
- cd server
- npm install
- node server.js

### 3. Setup Frontend
- cd contact-app
- npm install
- npm run dev

### 4. Open in Browser
- http://localhost:5173
